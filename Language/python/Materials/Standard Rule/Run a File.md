# How to run a Python file!

- As you can see, python files are marked with the `.py` extension.
- To run a python file, you need to open your IDE terminal, like:
Powershell,
CMD,
Git Bash,
or just a regular terminal, etc.
- Then, you need to navigate to the directory where the file is located. 

```txt
For example, Here, i have a file named "datatypes.py" in the "Basic" folder. 
The exact path of the file is in D:\learningMATERIAL\Language\python\Materials\Basic\datatypes.py
```
- After navigating to the directory, you need to run the file by typing the following format:
```txt
python filename.py
```

- So, in my case, i'll run the file by typing the following:
```txt
python datatypes.py
```

- Simple, right? Always remember to include the `.py` extension at the end of the file name.
