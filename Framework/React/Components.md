# Components
---
## What is a component?
A component is a reusable piece of code that encapsulates a piece of functionality. It can be as simple as a button or as complex as a full-fledged application.

Think of it as a small Lego brick that you can put together to build a bigger application. Components are the building blocks of React applications.

## Components in React
Components in React are JavaScript functions that return a piece of UI. The structure of a component is same like HTML structure, where you can found:
- <div> tag
- <span> tag
- <input> tag
- <button> tag
- <h1> tag
- <NameOfComponent> tag
